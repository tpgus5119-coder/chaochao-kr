# 일상 낱말 목차 — 처음부터 새로 (2026-08-31)

대표님 지시: "선배 단어나 과거에 있던 일상단어나 완전히 제외하고 처음부터 다시
목차 구성과 그 목차를 이루는 단어를 준비하라는 거야."

**이 목차는 기존 낱말을 다시 묶은 것이 아니다.** 목차를 먼저 정하고, 그 다음에
빈도 상위 낱말로 채운다.

## 근거

### ① 듀오링고 — 주제가 아니라 '할 수 있는 것(can-do)'

CEFR 의 can-do 진술이 뼈대다. 한 단원 = 한 대화 상황.
**레벨당 약 800낱말**, A1+A2 를 합치면 1,600 안팎.
→ [How are Duolingo courses evolving?](https://blog.duolingo.com/how-are-duolingo-courses-evolving/)

### ② 베트남어 교재 — 모두 상황 배열

**Colloquial Vietnamese** (Routledge) 14과 실제 차례:
인사 · 공항 · 호텔 도착 · 전화 · 길에서 · 식당 · 시장 · 후에/하노이 ·
은행 · 달랏/사이공 · 잡담 · 여행 계획 · 해변 · 귀국·작별
→ [Routledge](https://www.routledge.com/Colloquial-Vietnamese-The-Complete-Course-for-Beginners/HoaiTran-Nguyen-Vuong-Vuong/p/book/9781138950238)

| 교재 | 짜임 |
|---|---|
| Elementary Vietnamese (Harvard/Tuttle) | 대화 기반 14과, 문형 중심 |
| Complete Vietnamese (Teach Yourself) | **주제형 18과** — 자기소개 → 일상 → 전화 → 일 이야기 |
| VSL / Tiếng Việt cơ sở (베트남 국립대) | VSL2 = 12과, 신출 약 500낱말 |

공통 차례: **인사 → 자기소개·가족 → 숫자·시간 → 길·교통 → 식당·시장 →
숙소 → 하루 일과 → 날씨·건강 → 전화·약속 → 작별**

### ③ 우리는 여행자가 아니라 **살러 가는 사람**이다

Colloquial 의 '해변 · 여행 계획 · 달랏' 같은 관광 단원은 뺐다.
대신 **집 구하기 · 병원 · 은행 · 직장 · 도움 청하기**를 넣었다.
동기들이 베트남에서 일하며 살 사람들이기 때문이다.

### ④ 묶는 규칙

| 갈래 | 어떻게 | 근거 |
|---|---|---|
| **체계** — 숫자·요일·달·호칭 | 한자리에 **모아서** | 규칙이 보여야 만들어 쓴다 (`một·hai·ba` → `mười một`) |
| **나열** — 색깔·과일·옷 | 한자리에 **다섯 개까지** | 한꺼번에 외우면 서로 헷갈린다 (Tinkham·Erten: 회상 55% vs 44%) |
| 철자·소리가 닮은 것 | 한자리에 넣지 않는다 | 진짜 혼동 원인 (Ishii 2015) |

## 시중 것과 맞대 본 결과 — 빠졌던 것

**듀오링고 베트남어 과정 75단원 실제 목록**과 하나씩 맞대 봤다.
→ [Duolingo Vietnamese from English (75 Units)](https://duolingodata.com/dat/vifen75.html)

| 듀오링고에 있는데 우리에게 없던 것 | 어떻게 했나 |
|---|---|
| Describe colors | **색깔** 새로 넣음 — 물건 살 때 매일 쓴다 |
| Use common conjunctions / adverbs / determiners (3단원) | **이어주는 말**, **정도와 빈도**, **가리키는 말** 셋으로 넣음 |
| Express opinions (**3번 나온다**) | **생각과 의견 말하기** 새로 넣음 |
| Talk about occupations (2단원) | **직업** 새로 넣음 — 자기소개에 반드시 든다 |
| Communicate at school (2단원) | **학교와 배우기** 되살림 |
| Communicate when traveling | **여행과 묵을 곳** 되살림 (Colloquial 의 공항·호텔에 해당) |
| Say where things are / Describe location | **위치와 자리** 새로 넣음 (위·아래·안·밖) |
| Chat with your friends | **친구와 어울리기** 되살림 |
| Describe animals / Identify wild animals | **동물**은 따로 두지 않고 **먹을거리**(닭·돼지·소·생선)와 **자연**에 나눠 넣음 |
| Describe nature | **자연과 바깥** 새로 넣음 |
| Discuss sports | **쉬는 날과 취미**에 넣음 |
| Identify body parts · Express feelings · Describe qualities | 이미 있음 |

**Colloquial Vietnamese** 와 맞대서 더 넣은 것: **잡담**(안부·날씨 이야기 같은 가벼운 말),
**명절과 문화**(뗏 등 — 살러 가는 사람에게는 필수인데 관광 교재에는 없다).

## 목차 — 40꼭지

**한 꼭지 = 낱말 10개 + 그 낱말로만 만든 문장 2개** · 하루 최대 3꼭지(30낱말·6문장)

> 왜 10개인가: 한 번에 다루는 신출 낱말이 적을수록 오래 남는다(Nakata & Suzuki 2019).
> 무엇보다 **그 낱말로만 문장을 만들어야 하므로** 15개면 억지 문장이 나온다.

### 첫걸음
- **인사와 헤어짐** — 만나고 헤어질 때 인사한다
- **호칭 — 나와 상대를 부르는 말** — anh·chị·em·cô·chú 를 가려 쓴다
- **나이와 생일** — 나이를 묻고 답한다
- **이름과 소개** — 이름을 묻고 나를 소개한다
- **나라와 말** — 어느 나라 사람인지, 무슨 말을 하는지 말한다
- **숫자** — 수를 세고 읽는다
- **가족** — 가족을 소개한다
- **직업** — 무슨 일을 하는지 말한다

> **호칭을 앞에 두는 까닭**: 베트남어에는 중립적인 '당신'이 없다. 상대의 나이와 관계에 따라
> anh(형·오빠)·chị(누나·언니)·em(동생)·cô·chú 를 골라야 하고, **인사말 자체가 호칭 없이
> 성립하지 않는다**(Chào anh / Chào chị). 그래서 교재들이 1과에 넣는다.
> 호칭을 고르려면 나이를 알아야 하므로 나이도 함께 앞에 둔다.

### 말을 잇는 뼈대
- **자주 쓰는 동작** — 하다·가다·주다 같은 기본 동사를 쓴다
- **가리키는 말** — 이것·그것·여기·저기를 쓴다
- **이어주는 말** — 그리고·그러나·그래서로 말을 잇는다
- **정도와 빈도** — 조금·아주·가끔·다시를 쓴다
- **묻는 말** — 무엇·어디·언제·누구·왜·얼마로 묻는다

> 이 다섯은 장면에 매이지 않지만 **문장을 만들려면 반드시 필요하다.**
> 듀오링고도 conjunctions·adverbs·determiners 를 따로 단원으로 둔다.

### 하루
- **시간 말하기** — 몇 시인지 묻고 답한다
- **요일과 날짜** — 무슨 요일·며칠인지 말한다
- **하루 일과** — 하루에 하는 일을 차례로 말한다
- **집과 방** — 사는 곳과 방 안의 것을 말한다
- **살림살이** — 집안일에 필요한 말을 한다
- **위치와 자리** — 위·아래·안·밖으로 어디 있는지 말한다

### 먹고 사기
- **먹을거리** — 무엇을 먹는지 말한다 (닭·돼지·소·생선 포함)
- **마실거리** — 무엇을 마시는지 말한다
- **맛과 느낌** — 맛과 양을 말한다
- **식당에서 시키기** — 주문하고 계산한다
- **색깔** — 빛깔로 물건을 가려 말한다
- **값 묻고 깎기** — 값을 묻고 깎는다
- **가게에서 사기** — 물건을 고르고 산다
- **옷과 입기** — 옷을 고르고 치수를 말한다

### 거리에서
- **길 묻기와 방향** — 길을 묻고 방향을 알아듣는다
- **탈것과 이동** — 오토바이·버스·택시를 타고 간다
- **도시와 장소** — 어디에 무엇이 있는지 말한다
- **은행·우체국·관공서** — 돈을 바꾸고 서류를 낸다
- **여행과 묵을 곳** — 표를 끊고 묵을 곳을 잡는다

### 몸과 마음
- **몸과 아픈 곳** — 어디가 아픈지 말한다
- **병원과 약국** — 진료를 받고 약을 산다
- **기분과 마음** — 기분을 말한다
- **사람됨과 성격** — 사람을 설명한다

### 어울려 살기
- **날씨와 철** — 날씨와 계절을 말한다
- **자연과 바깥** — 산·강·나무·동물을 말한다
- **쉬는 날과 취미** — 쉬는 날에 하는 일을 말한다 (운동 포함)
- **친구와 어울리기** — 사람을 사귀고 함께 논다
- **잡담** — 안부와 날씨로 가벼운 말을 주고받는다
- **명절과 문화** — 뗏 같은 명절 자리에서 말한다
- **전화와 약속** — 전화로 약속을 잡는다
- **일과 직장** — 일터에서 기본적인 말을 한다
- **생각과 의견 말하기** — 좋다·싫다·낫다로 뜻을 밝힌다
- **도움이 필요할 때** — 곤란할 때 도움을 청한다

전체 **40꼭지 × 50낱말 = 2,000낱말** — CEFR A2 상단에 닿는 분량이다.

## 다음 단계 — 낱말 채우기

목차가 정해졌으니 이제 꼭지마다 50낱말씩 고른다.

**고르는 잣대**
1. **빈도 상위에서 고른다** (Nation·Schmitt: 고빈도 2~3천을 먼저)
2. 그 꼭지 장면에서 **실제로 필요한** 말이어야 한다
3. **앞 꼭지에서 이미 배운 말은 다시 넣지 않는다**
4. 문장 2개를 **그 열 낱말로만** 만들 수 있어야 한다 —
   못 만들면 낱말 구성이 잘못된 것이다

**만드는 차례**
```
① 꼭지마다 낱말 50개 고르기        (Qwen 초벌 → 사람이 손봄)
② 앞 꼭지와 겹치는 것 걷어내기      (기계로)
③ 꼭지 안에서 열 개씩 나누기 — 체계는 모으고 나열은 흩는다
④ 열 낱말마다 문장 2개 만들기      (그때까지 배운 낱말로만)
⑤ 검증: 안 배운 낱말이 문장에 섞였나 (tools/assemble.py 가 하던 검사)
⑥ 발음·소리·그림
```
