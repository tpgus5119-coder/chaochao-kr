# 짜오짜오 — 정해 둔 기준 (하나의 파일)

대표님 지시 (2026-09-02): "다 기준을 정했잖아. 헷갈리지 않도록 하나의 파일로."
**여기가 유일한 기준이다.** 다른 문서와 어긋나면 이 파일이 맞다.
바꿀 때는 이 파일을 고치고, 왜 바꿨는지 한 줄 적는다.

## 4. 낱말 — 어떻게 검수하나

### 한 칸에 낱말 하나
- 잣대는 **길이가 아니라 사전에 한 표제어로 실리는가**
- `bảo hiểm y tế`(건강보험)는 네 음절이어도 한 낱말
- `màu đỏ`는 두 음절이어도 `màu`+`đỏ` 두 낱말
- 사전에 없으면 **쪼개 본다.** 조각이 모두 아는 낱말이면 조각을 따로 넣는다
- **다만 뜻이 부분의 합이 아니면 안 쪼갠다** — `xe đạp`(자전거)를 차+밟다로 쪼개면 자전거가 사라진다

### 검수 차례
1. **우리 사전** `data/_vi_words.json` (47,341 표제어) — 공짜·즉시
2. **위키낱말 실시간 조회** — 우리 사전에 없는 것만
3. **최종: 사전 뜻풀이 대조** — Qwen 에게 뜻풀이를 쥐여 주고 고르게 한다
4. **사람이 마지막 판정**

### 발음
`tools/vi_kr.py` 가 만든다. **AI 금지** — 같은 글자면 늘 같은 결과라야 검산이 된다.
받은 발음에 한글이 아닌 글자가 있으면 다시 만든다 (`học → [học]` 사고).

## 5. 소리(TTS) — 어떻게 만들고 검수하나

| 무엇 | 도구 |
|---|---|
| 북부 남녀 | `edge-tts` (`gen_audio.py`) |
| 남부 남녀 | `v-tts` (`gen_south_vtts.py`) |
| **검수** | **Whisper** (`tts_check.py`) — 만드는 도구가 아니다 |

### 검수 항목
| 무엇 | 어떻게 |
|---|---|
| 낱말마다 네 목소리가 다 있나 | 해시로 센다 |
| 네 목소리가 서로 다른가 | 파일 해시 비교 |
| 북부·남부가 갈리나 | 크기 무리 (북 ~10.7KB · 남 ~4.8KB) |
| **낱말을 제대로 말하나** | Whisper 받아쓰기 |

**받아쓰기는 두 음절 이상에서만 믿는다.** 한 음절은 0.3초라 못 알아듣는다
(실측: 두 음절 이상 0.74 · 한 음절 0.58).

### 재생 속도
파일은 한 벌. **1배속 / 0.7배속**을 재생으로 조절한다(설정 「소리 속도」).
느린 파일을 따로 굽지 않는다 — 용량만 늘고, `playbackRate` 는 성조를 지켜 준다.

## 6. 그림 — 어떻게 만들고 검수하나

| 무엇 | 도구 |
|---|---|
| 글감 | Qwen (`img_prompt_gen.py`) |
| 굽기 | **Draw Things** FLUX schnell **4단계** 512×512 |
| 붙이기 | `img_link.py` (같은 낱말·같은 뜻) |
| 검수 ① 뜻을 알려주나 | Qwen (`img_audit.py`) |
| 검수 ② 이상한 그림인가 | **Qwen3-VL 8B** 또는 사람 |

- **8단계로 굽지 않는다.** schnell 은 4단계용이라 시간만 두 배 든다
- **그릴 수 없는 말에는 그림을 안 붙인다** — 붐비는·사라지다·답답하다
- Qwen 판정만으로 떼지 않는다. **말끝이 움직씨·그림씨인 것만** 뗀다 (실측: 20%가 잘못 걸렸다)
- 그림 파일은 **지우지 않는다** — 판정이 틀리면 되붙인다

## 8. Qwen 에게 일 시키는 법

### 네 관문 — 하나라도 걸리면 안 준다 (`tools/route.py`)
① 검산할 수 있나 · ② 틀리면 눈에 띄나 · ③ 지어낼 자리가 없나 · ④ 시간이 되나(1.2초/건)

### 묻는 법 넷
1. **만들게 하지 말고 고르게 한다** — "뜻이 뭐냐"(✗) → "이 뜻풀이 중 맞는 것"(○)
2. **근거를 적게 한다** — "어느 대목을 봤는지 적어라. 못 적으면 고치지 마라" (224→17)
3. **개수를 채우라고 하지 않는다** — "열 개뿐이면 열 개만" (안 그러면 255개를 지어낸다)
4. **받은 답은 규칙으로 다시 거른다** — 한글인가 · 12자 이내인가 · 지어낸 숫자인가

### 거르는 규칙도 한 번은 돌려본다
"베트남어 낱말이 한국어 기사 본문에 있어야 한다"고 걸렀다가 **전부 죽었다** (2026-09-02).

### 모델은 한 번에 하나만 올린다
24GB 맥이다. 9B(10.4GB) + VL(9.9GB) = 20.3GB 면 Draw Things 가 못 돈다.
글 일 → 9B · 그림 굽기 → 아무것도 안 올림 · 그림 검수 → VL 만.
**Whisper 는 CPU 라 그림 굽기와 같이 돌려도 된다.**

## 9. 일을 마쳤다고 말하기 전에
1. 숫자를 확인했나 (몇 개 처리, 몇 개 실패)
2. **눈으로 봤나** (그림·카드는 실제로 열어 본다)
3. **올렸나** — `git push origin main`. 커밋만으로는 앱이 안 바뀐다
4. 판번호를 갱신했나 — `python3 tools/stamp.py`
5. **자동 작업은 실제로 돌려 봤나** — 등록만 하고 안 도는 일이 있었다

## 10. 조용한 실패를 조심한다
에러 없이 **결과만 잘못 나오는** 것이 가장 위험하다. 겪은 것들:
- 쪽 넘기기 값을 하나만 보내 사전이 5,000개에서 끊김
- 요청이 실패해도 조용히 멈춰 9,499개에서 끊김
- 위키가 `429`(그만 걸어라)를 줘 절반이 거짓 '없음'
- 여럿을 묶어 보냈더니 하나만 답해 83%가 거짓
- `import` 만 해도 `main()` 이 돌아 검수 안 된 낱말이 섞임
- `git push` 를 안 해 커밋 33개가 앱에 반영 안 됨
- launchd 가 다른 파이썬을 잡아 PIL·pptx 가 없는데 "끝"이라고 찍음

## 11. 일을 잘게 쪼개 누가 하나

표시: ● 잘함 · ◐ 검수 필요 · ✗ 못함 · **기계** = AI 가 필요 없음

| 일 | Qwen | 기계 | 클로드·사람 |
|---|---|---|---|
| 그림 글감 | 40% | 60% | — |
| 그림 굽기 | 0% | **100%** | — |
| 그림 검수 | 25% | 25% | **50%** |
| 앱에 넣기 | 0% | **100%** | — |
| 목차 정하기 | 30% | — | **70%** |
| 낱말 고르기 | 40% | 40% | 20% |
| 뜻·발음 검수 | 25% | 50% | 25% |
| TTS 매치 검수 | 0% | **100%** | — |
| 남북·남녀 검수 | 0% | **100%** | — |

**스물다섯 가지 일 가운데 열넷이 기계 몫이다.**
모델을 고르는 것보다 **셀 수 있는 일을 세는 것**이 더 많이 아낀다.

### 셀 수 있는 일들 (실제로 이렇게 했다)
- 낱말에 소리 파일이 있나 → 낱말을 해시로 바꿔 `audio/{f,m,sf,sm}/n/<해시>.mp3` 를 센다
- 네 목소리가 다른가 → 파일 해시 비교
- 북부·남부가 갈리나 → 크기 무리 (북 ~10.7KB · 남 ~4.8KB)
- 낱말이 사전에 있나 → `data/_vi_words.json` (47,341)
- 한 낱말인가 → 사전 표제어면 하나. 아니면 쪼개 본다
- 발음이 한글인가 → 정규식. 아니면 `vi_kr.word()` 로 다시
- 그림이 겹치나 → 파일 해시

## 12. 모델 — 무엇을 쓰나

| | 크기 | 이 맥에서 | 그림 보기 | 소리 듣기 |

- 그림 검수는 "무엇이냐"가 아니라 **"X 로 보이나 예/아니오"** 로 묻는다 (5중 2 틀림 → 크게 나아짐)

## 13. 낱말이 사는 곳이 **두 군데**다
```
data/days.json    하루 5분 (108일 1,080낱말)   ← 2권
data/order.json   기본기·문법 / 직무           ← 1권·3권
```
검수 도구가 `order.json` 만 읽어 **하루 5분 그림 1,080장을 통째로 빠뜨린 적이 있다.**
소리 검수도 같은 구멍이 있었다. **새 도구를 만들면 두 곳을 다 읽는지 확인한다.**
