# 시험 풀이 전략 — 토익 해부 + EPS 실측 + 12개 송출국 조사

2026-08-30 전면 개정. 요원 15갈래 조사(검색·열람 548회) + 공식 CBT 체험판 직접 조작 +
UBT 공식 매뉴얼(NSDevil·공단 공동, 19쪽) 원문 판독 + 학술 논문 12편.
**용도: 앱 '학습' 과정에 풀이 요령을 전부 넣기 위한 원자료.**
원칙(사용자 지시): 모의고사는 실제 시험 그대로만. 요령은 전부 학습 쪽에.

---

## 0. 가장 먼저 — EPS는 한 시험이 아니다 (CBT / UBT)

**베트남은 CBT(일반)다** — 공단 공식 사이트 시험일정에 명기. 스리랑카·필리핀·인도네시아
·네팔 공고는 UBT(태블릿). 두 방식은 조작 규칙이 정반대에 가깝다.

| | **CBT (베트남)** — 공식 체험판 실측 | **UBT (타국)** — 공식 매뉴얼 판독 |
|---|---|---|
| 답 변경 | **한 번 고르면 잠김** (유의사항 원문 + 소스코드 '한번 체크하면 해제 불가' + 클릭 실측) | **제출 전까지 변경 가능(강한 함의)** — 잠금 경고가 매뉴얼 어디에도 없고 "제출하면 못 바꾼다"만 있음 |
| 타이머 | **읽기·듣기 따로.** 읽기 시간이 끝나면 강제로 듣기로 넘어감(timer JS 실측) | **50분 단일 카운트다운** — 25+25는 배분 안내일 뿐 |
| 이동 | 읽기 안 PREV/NEXT 순차만, 번호판은 표시 전용. **듣기 진입 후 복귀 불가** | 격자에서 자유 이동, 듣기·읽기 자유 왕복. 잠기는 건 **오디오 재생 중**뿐 |
| 듣기 | **자동 진행** — 문항 표시와 동시에 재생, 이동 버튼이 사라짐 | **문항별 수동 재생** — 내가 ▶를 눌러야 시작, 연달아 2회, 끝나면 재청취 불가 |
| 두 번 재생 | 음원 안에 "다시 들으십시오" 포함 | "same content twice" — 정책은 동일 |
| 안내 | 정보확인·유의사항 **음성 안내** + **의무 연습시험** | 방송 없음. 튜토리얼 영상 1:27(스킵 가능) + 음량 조절(샘플 재생 필수) |
| 제출 | — | **시작 30분 후부터** 제출 가능, 시간 종료 시 푼 문항만 자동 제출 |
| 부가 | — | AI 얼굴인식(80%)·AI 감독("고개 돌리지 마시오") · 제출 후 **색각검사 12문항**(문항당 2:30, 7정답 통과/5오답 탈락) |

주의: CBT 체험판은 구형(50문항/70분) 포맷이라 현행 CBT 실물과 100% 같다는 보장은 없다.
그러나 공단이 지금도 배포하는 공식 연습 도구이므로 **베트남용 기본값은 이 규칙**으로 한다.
(UBT 모드는 나중에 다른 송출국으로 확장할 때의 자산이다.)

**공통 확정 규격**: 40문항(읽기 20 + 듣기 20) · 100점 · 50분 · 4지선다 · 상대평가
(제조업 하한 60 / 그 외 45 / 어업특례 30 P/F — 하한은 입장권일 뿐, 성적순 선발).

## 1. 토익이 쪼갠 방식 — 전모

### 1-1. LC: 선읽기(先読み)의 초 단위 설계

| 자리 | 실측 | 그동안 하는 일 |
|---|---|---|
| Part 1 디렉션 | **약 90초** | Part 3 첫 세트(32~34) 설문 선읽기 (또는 P1 사진 6장 훑기) |
| Part 2 디렉션 | 약 30초 | Part 3 다음 세트 선읽기 |
| Part 3·4 디렉션 | 각 약 30초 | 해당 파트 첫 세트 + **도표 문항 먼저** |
| P1 문항 뒤 | 5초 | 앞 3초 마킹 + 뒤 2초 다음 사진 |
| P2 문항 뒤 | 5초 | 즉시 마킹(선읽기 개념 없음 — 문제지에 아무것도 없음) |
| P3·4 설문 1개 | 읽기+8초 쉼 = 12~13초 × 3 | 만점자 리듬: 대화 중 답 확정 → 설문 방송 중 3문항 일괄 마킹(12초) → **남는 24~26초 통째로 다음 세트 선읽기** |
| 도표 문항 쉼 | 8초 대신 **12초** | 도표는 디렉션 때 미리 봐 둔다 |
| LC 종료 | "This is the end of the Listening test" 방송 | 이 방송 전에 RC를 펴면 **규정 위반** |

- 선읽기는 **설문만, 보기는 안 읽는다** — 4개 중 3개가 오답이라 입력 자체가 낭비.
  '주어+의문사'만 초요약(the man + where)해 주문처럼 되뇐다.
- **리듬이 무너지면 세트를 버린다**: "2문항째 설문이 낭독되면 무조건 다음 세트로" 같은
  자기 데드라인. 버릴 때도 주제 문항과 '다음에 할 일' 문항은 사수, 세부·추론은 포기.
- P4(1인 담화)는 **담화 중 선읽기 금지** — 놓치면 복구 단서가 없다.

### 1-2. LC: 파트·유형별 손

- **P1**: 인물 사진은 인원수→특징→동작→장소, 무인물은 사물→장소→상태→위치 순 스캔.
  오답 3규칙 — ①사진에 없는 명사 ②유사발음(pile/file) ③추상 묘사(생각·의견).
  문법 함정: being+p.p.(지금 그 동작 중이어야만 정답)·현재완료·wearing↔putting on.
- **P2**: **첫 0.5초 의문사 판별**이 전부의 시작. 판정 5항목: 의문사→주어 일치→시제 일치
  →대화 성립→에코 단어 경계. 25문 중 간접응답 약 7문 — "잘 모르겠는데요" 류는 거의 정답,
  질문 단어를 그대로 반복하는 보기는 거의 오답.
- **P3·4 의도파악**: 따옴표 인용문을 다른 설문보다 **먼저** 읽고, 방송에서 그 대사의
  **직전 발언(계기)과 직후 반응(뒷받침)**에 집중.
- **P3·4 도표**: 도표의 한쪽 축이 보기에 나오므로, 들을 것은 도표의 **다른 쪽** 축이다.

### 1-3. RC: 유형별 첫 동작

- **P5 (30문항 약 10분, 문항당 20초)**: **보기부터 스캔**해 문법이냐 어휘냐를 가른다 —
  같은 어근의 파생형 나열이면 문법(해석 없이, 빈칸 앞뒤만, 3초), 다른 단어 나열이면
  어휘(해석 필요, 시간 더 씀). 동사 문제는 주어→수일치→태→시제의 고정 순서.
- **P6 (16문항 약 10분)**: 문장삽입은 대명사·접속부사·반복명사가 가리키는 것을
  [1]~[4] 앞뒤에서 찾는다. 지시 대상은 반드시 앞에 있어야 한다.
- **P7 (54문항 약 54분, 단일지문 문항당 50초)**:
  - 지문 유형별 첫 동작 — 이메일: 발신·수신·목적부터 / 광고: 조건 문구 표시하며 /
    채팅: 인용 앞뒤 맥락 / 기사: 최고 난도, 주제·추론과 짝.
  - 문제 유형별 우선순위 — **주제·세부·동의어 먼저, NOT과 긴 추론은 맨 뒤**
    (NOT은 보기 4개를 전부 대조해야 해서 최장 시간).
  - 설문 읽기 규칙 — 2·3문항 지문은 설문 전부 읽고 진입, **4·5문항 지문은 앞 2개만**
    (다 기억 못 한다). 2·3문항 지문에서 아낀 시간을 4·5문항에 몰아준다.
  - 삼중지문 — 문제 5개를 먼저 훑어 **문제→지문 지도**를 만들고 지문을 한 번씩만 읽는다.
    한 지문만 읽고 보기가 2개 남으면 = 연계 문제라는 신호.
  - 순서 논쟁 — A파: 이중·삼중을 머리가 맑은 초반에 먼저(다수 수험생이 뒤에서 포기하므로
    여기가 변별). B파: 앞에서 순차 + 시간이 모자라면 **4문항짜리 단일지문을 버린다**.
  - ETS 통계: P7 54문 중 약 70%가 지문을 **바꿔 말한(패러프레이즈)** 정답 —
    같은 단어가 보이면 오히려 의심.

### 1-4. 토익 → EPS 이식 판정표

| 토익 기술 | EPS-CBT(베트남) | 근거 |
|---|---|---|
| 디렉션 틈 선읽기 | **✗ 이식 불가** | 문항 사이 틈 없음, 듣기는 자동 진행 |
| 쉬운 것 먼저·나중에 복귀 | **△ 읽기만** — 듣기 진입 전까지 | 읽기 안 왕복 가능(실측), 듣기는 복귀 불가 |
| 답 표시 뒤 수정 | **✗** | 한 번 고르면 잠김 |
| 문항당 초 못 박기 | **○** | 유형별 30/45/75/120/150초 (아래 3장) |
| 설문 핵심어 표시 | **○** | 그대로 |
| 유형별 첫 동작 | **○** | 아래 2장 |
| NOT은 맨 뒤 | **○** | 체험판에도 NOT 유형("잘못 설명한 것") 실존 |
| 도표 먼저 보기 | **○** | 표지판·그래프 문항 다수 |
| 세트 버리기 규칙 | **○ (변형)** | "듣기로 넘어가기 전 안 푼 읽기 = 영원히 잃음" |

## 2. 12개 송출국은 어떻게 가르치나 — 건질 것만

- **베트남 (Korealink·ANT EDU·epstopikvn)**: ①빈칸 금지(감점 없음 — 무조건 찍기)
  ②그림 문제: 아는 물건이면 즉답, 모르면 보기 4개의 **핵심 동사만** 비교(어미가 같으면 건너뜀)
  ③도표는 비교 어휘 세트(가장/제일·많다/적다·N보다)만 외우면 기계적으로 풀림
  ④독해 소재는 거의 '한국 직장·생활 문화'로 고정 — 표준교재 문화 단원이 곧 독해 대비
  ⑤학원들은 "실제 화면 99% 복제" 모의 CBT로 **조작 미숙 감점**부터 없앤다(3회 무료 뒤
  99,000~399,000동 = 5,200~21,000원). ⑥**ANT EDU: 2026년 시험 오디오가 예년보다
  15% 빨라졌다며 1.2~1.5배속 듣기 훈련** 처방.
- **인도네시아 (응시 세계 1위)**: 2025 제조업 커트라인 **97.5/100 — 40문항 중 1개만
  틀려야 한다.** 그래서 전략이 '통과'가 아니라 '만점 사냥'. 표준교재 1일 1과,
  하루 어휘 500~1,000개 노출, 숫자(한자어·고유어 수사)는 즉답 수준. 받침 연음 규칙을
  모르면 아는 단어도 못 듣는다고 강조.
- **네팔**: "읽기는 되는데 듣기에서 떨어진다" 진단 → 하루 1~2시간 듣기 몰입.
  1회차에 보기 2개로 압축, 2회차에 확정. 첫 시도 낙방을 전제로 한 장기 플랜이 표준.
- **태국**: **3회독 풀이법** — 1회 실전 시간, 2회 오답을 '어휘/문법/속도' 3종으로 분류,
  3회 틀린 것만. 지문에서 **숫자·날짜·가격·부정어부터 스캔**(함정이 거기서 나옴).
- **몽골**: 자가진단 기준 — **유튜브 한국어를 1.5~2배속으로 이해되면 듣기 만점권**
  (시험 음성이 느리게 느껴진다는 논리). 지시문의 '맞는 것/틀린 것' 구분 주의.
- **공통 (전 언어권 일치)**: 사설 자료 말고 **표준교재 + 공개문제집**만.
  과거 '공개 2,000문항 통암기' 전략은 2013년 비공개 출제 전환으로 죽었다 —
  은행은 유형 익히기용, 실력은 교재로.

**한국어 강의 시장은 비어 있다**: 국내 시판 EPS 교재는 4권 전부 품절(2012·2017년 책),
시대에듀도 없음. 유일한 전략 강의는 TOPIK Mate($7~35, 20강 중 '고득점 전략' 2강, 6개 언어
자막). 공단 공식 E-Class는 표준교재 60강(11개 언어, 세종학당 경유)이지만 **회화 강의**지
풀이 전략이 아니다. → 유형별 전략을 베트남어로 체계화한 것은 아직 아무도 없다.

## 3. 읽기 25분 배분 (실측 비율, CBT 기준)

| 유형 | 20문항 중 | 문항당 | 손 |
|---|---:|---:|---|
| 그림 보고 고르기 | 4 | 30초 | 그림→낱말 떠올리기→보기에서 찾기. 보기 길이가 다 같아(최장-최단 1자) 길이로 못 찍음 |
| 빈칸 | 6 | 45초 | 빈칸 앞뒤 두 낱말만. 조사 결합으로 품사부터 좁힘 |
| 질문에 답하기 | 7 | 75초 | 설문 핵심어 표시→훑기 |
| 긴 지문(연계 2문항) | 2 | 120초 | 설문 먼저→근거 문장. NOT은 마지막 |
| 글 읽고 물음 | 1 | 150초 | 지문 먼저 훑기 |
| 합 | 20 | | 21.8분 + **여유 3.2분** |

여유 3.2분의 뜻(CBT): **안 푼 문항을 0개로 만드는 시간.** 듣기로 넘어가는 순간
안 푼 읽기 문항은 영원히 잃고, 남은 읽기 시간도 증발한다(실측).

## 4. 학술 근거 — 무엇이 진짜 효과가 있나

- **Sherman 1997 (Language Testing)**: 듣기 실험 4조건 중 최고 성적은 **'1차 듣기 →
  질문 읽기 → 2차 듣기' 샌드위치**. 미리 읽기는 "도움된다고 느껴지지만" 실제 향상은
  불일치. → **EPS의 2회 재생 구조가 정확히 샌드위치다. "1회차는 듣기만, 2회차에 확정"
  전략에 실험적 근거가 있다.**
- **O'Grady 2021**: 설문 **줄기만** 미리 읽기 > 보기까지 읽기. 이득은 **하위권에 집중**
  — EPS 응시자층과 정확히 겹친다.
- **Paton 2018**: 초급자(TOEIC Bridge 90~140)에게 전략만 가르치면 **오히려 떨어질 수
  있다**(인지 과부하). → 우리 학습 과정에서 전략 차시는 **어휘·해독이 선 다음**에 배치.
- **Hao 외 2025 (RER 메타분석, 28편)**: 시험 기술을 가르친 중재 g=.35 vs 안 가르친 .05.
  **시간 재는 모의고사 '단독'은 유의하지 않음** — 모의고사+전략+문제집 묶음이어야 한다.
  기출 노출 경험자 g=.69 vs 무경험 .06.
- **Dalman & Plonsky 2022**: 듣기 전략 지도 d=.69 — **4기능 중 듣기가 전략 훈련의
  투자수익 최고.** 네팔의 "듣기에서 떨어진다" 진단과 정합.
- **Chang & Read 2006**: 듣기 지원 효과 순위 — 주제 배경지식 > 반복 청취 > 문항 미리보기 >
  어휘 사전 학습. → 듣기 차시는 단어장보다 **주제 미리 열기**로 시작.
- **Ackerman & Lauterman 2012**: 화면 시험은 실제와 같은 **화면+시간 제한**으로 연습해야
  하고, 화면 학습자는 자기 실력을 과대평가한다. → 모의고사를 실제 규칙 그대로 만드는
  우리 원칙의 근거.
- **Plonsky 2011**: 전략은 **적게 골라 깊게** 오래 연습(d=.49). 목록 뿌리기 금지.

## 5. 앱에 넣을 것 — 자리 배정 (사용자 지시: 요령은 전부 학습에)

### 모의고사 = CBT 재현 (요령·시계 표시 금지)
1. 답 잠금(한 번 고르면 끝) 2. 읽기 안 순차 이동, 번호판 표시 전용
3. 읽기 타이머 만료 시 강제 듣기 전환 / 조기 진입 가능·복귀 불가·시간 비이월
4. 듣기 자동 진행 + 이동 버튼 숨김 + 2회 재생 5. 유의사항 화면 + 연습 문항(의무)

### 학습 '전략 과정' 차시안 (17차시)
1. 시험의 정체 — 상대평가·커트라인은 입장권일 뿐 (인니 97.5점 사례)
2. CBT 조작 규칙 — 잠금·이동·강제 전환 (조작 미숙 감점 제거)
3. 시간 배분 — 유형별 30/45/75/120/150초 + 여유 3.2분의 용도
4. 그림 문항 — 그림→낱말→보기, 길이로 못 찍는 이유
5. 빈칸 문항 — 앞뒤 두 낱말 + 조사로 품사 좁히기
6. 도표·그래프 — 비교 어휘 세트 하나로 끝내기
7. 표지판 — 모양·색 분류(빨간 원=금지·노란 삼각=경고·파란 원=지시)
8. 독해 — 소재가 고정돼 있다(직장·생활 문화), 주제 예측 돌파
9. NOT·연계 문항 — 맨 뒤로 미루는 이유
10. 듣기 1 — 샌드위치: 1회차는 듣기만, 2회차에 확정 (Sherman 근거)
11. 듣기 2 — 숫자·시각·가격 즉답 훈련 (한자어·고유어 수사)
12. 듣기 3 — 받침·연음: 아는 단어를 못 듣는 이유
13. 듣기 4 — 소거법: 성별·시제·에코 단어로 지우기
14. 안 푼 문항 0개 만들기 — 빈칸 금지 + 듣기 진입 전 마무리
15. 3회독 복습법 (태국식) — 오답을 어휘/문법/속도로 분류
16. 자가진단 — 배속 듣기로 내 위치 재기 (몽골식)
17. 시험 전날·당일 — 지참물, 신분 확인, 멘탈 (베트남 규정 기준)

배치 규칙(Paton): 전략 차시는 표준어휘 기초를 마친 학습자에게만 연다.
설계 규칙(Plonsky): 차시당 전략 1개, 반복 연습 붙임.
