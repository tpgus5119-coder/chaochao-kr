## 2. 설정 — 공식 문서로 확인한 값 (2026-08-31)

**앱 화면에서 무엇을 만지든 스크립트가 보내는 값이 이긴다.** 값은 `tools/gen_word_img.py` 안에 있다.

| 항목 | 값 | 왜 |
|---|---|---|
| 모델 | **FLUX.1 [schnell]** | **Apache 2.0 이라 상업 이용이 자유롭다.** dev 판은 비상업이니 쓰면 안 된다 |
| steps | **8** | BFL 공식 기본값은 4, Draw Things 공식 위키는 schnell 을 "4-8". 실측에서 8이 사람 몸·소품이 뚜렷하게 나았다(22초→35초) |
| cfg (Text Guidance) | **1 = 끔** | BFL 공식: 가이던스는 flux-dev 전용. schnell 은 `guidance_embed=False` |
| shift | **1 = 끔** | BFL 공식 코드가 schnell 에서만 시프트를 끈다: `shift=(name != "flux-schnell")`. 위키의 "Shift 2.8-4" 는 dev 용이다 |
| 샘플러 | **Euler A Trailing** | Draw Things 가 Trailing 계열을 권한다. 실측 39.7초(DPM++2M Karras 는 68.7초) |
| 크기 | **512×512 → 384 로 줄여 저장** | 1024 로도 구워 견줬더니 **512 가 낫다**. 1024 는 같은 스텝을 4배 넓은 화면에 나눠 쓰느라 그림이 밋밋해진다 |

### 반드시 알아야 할 두 가지

**① 부정 프롬프트(negative prompt)는 아예 안 먹는다.**
schnell 은 CFG 를 안 쓰기 때문이다. 앱 설정에 "text, watermark…" 가 적혀 있어도 무효다.

**② 프롬프트에 "no text", "without hands" 를 쓰면 오히려 그것을 부른다.**
확산 모델은 부정어를 긍정으로 읽는다. 실제로 '손 감춰라'가 손을 불렀다.
→ 없애고 싶으면 **다른 것으로 바꿔 적는다** (손가락으로 가리키기 → 화살표 팻말).

## 3. 무엇을 굽나 — 두 가지

### ㉮ 낱말 그림 (`tools/gen_word_img.py`)

```bash
cd "/Users/leesehyeon/베트남어-어플"
python3 tools/gen_word_img.py            # 아직 없는 것만 굽는다
python3 tools/gen_word_img.py --limit 20 # 스무 장만
```
- 글감은 `data/_imgprompts.json` (1,448개, `tools/img_prompt_gen.py` 가 만든다)
- 파일 이름 `img/w-<해시>.webp` — 해시는 **한국어 뜻**에서 나온다.
  뜻이 같으면 두 낱말이 한 그림을 나눠 쓴다
- 씨앗도 파일 이름에서 나오므로 **다시 돌려도 같은 그림**이 나온다
- 이미 있는 파일은 건너뛴다 → 아무 때나 끊고 다시 돌려도 된다

**⚠️ 굽기만으로는 앱에 안 나온다.** 반드시 이어 붙이기를 해야 한다:
```bash
python3 tools/img_link.py        # order.json 의 img 칸을 채운다  ← 이걸 빼먹으면 헛일
python3 tools/img_share.py --write   # 뜻이 같으면 두 과정이 나눠 쓴다
```

남은 장수 세기:
```bash
python3 -c "
import json,pathlib,re,hashlib,unicodedata as U
R=pathlib.Path('.')
pr=json.loads((R/'data/_imgprompts.json').read_text(encoding='utf-8'))
o=json.loads((R/'data/order.json').read_text(encoding='utf-8'))
def walk(v):
    for t in (v.get('tracks') or [v]):
        for c in t['chapters']:
            for l in c['lessons']: yield from l['words']
need=set()
for v in o['vols']:
    for w in walk(v):
        if w.get('img'): continue
        k=re.sub(r'\s+',' ',U.normalize('NFC',w['ko']).split('/')[0].split('(')[0]).strip()
        if k in pr: need.add(k)
miss=[k for k in need if not (R/'img'/('w-'+hashlib.sha1(U.normalize('NFC',k).encode()).hexdigest()[:10]+'.webp')).exists()]
print('아직 안 구운 낱말', len(miss))"
```

## 4. 자동으로 도는 것

`~/Library/LaunchAgents/chaochao.img.plist` 가 **한 시간마다** `tools/img_watch.py` 를 돌린다.
카드뉴스를 먼저 만들고, 그다음 빠진 낱말 그림을 한 번에 150장까지 굽는다.

```bash
launchctl list | grep chaochao                              # 확인
tail -20 img_watch.log                                      # 기록
launchctl unload ~/Library/LaunchAgents/chaochao.img.plist  # 멈추기
launchctl load   ~/Library/LaunchAgents/chaochao.img.plist  # 켜기
launchctl start  chaochao.img                               # 지금 한 번 돌리기
```

**큰 작업(파일 대량 수정·리베이스) 전에는 먼저 unload 해라.**

## 5. 그림 품질 — 지켜야 할 것

- **그림은 구체어에만.** 추상어(고요하다·전문가·적합하다)에는 일부러 안 붙인다.
  그림이 뜻을 못 알려 주면 없느니만 못하다 — 엉뚱한 것을 외우게 된다.
  `tools/img_audit.py` 가 이 잣대로 판정한다(판정만 하고 지우지는 않는다).
- **손으로 그린 그림은 AI 가 덮지 않는다.** 개수·국기·달력은 생성 모델이 늘 틀린다
  (태극기 괘가 네 개 다 엉뚱했고, 베트남 국기 별이 흰색이었다).
  `tools/draw_exact.py` 에 손으로 그린 목록이 있고 `img_watch.py` 가 이것을 막아 준다.
- **글자는 굽지 마라.** 챕터 표지의 글자는 `gen_covers.py` 가 PIL 로 직접 찍는다.

## 6. 자주 나는 문제

| 증상 | 까닭 | 할 일 |
|---|---|---|
| 아무것도 안 만들어진다 | Draw Things 가 꺼져 있다 | 1번 확인 |
| 만들었는데 앱에 안 나온다 | `img_link.py` 를 안 돌렸다 | 3-㉮ 참고 |
| 같은 그림이 여러 곳에 | 씨앗이 같다 | 카드뉴스는 고쳤다. 낱말은 뜻이 같으면 **일부러** 나눠 쓴다 |
| 그림에 글자가 박힌다 | 확산 모델의 버릇 | 글감에서 글자 나올 만한 말을 뺀다. 부정어로는 못 막는다 |
| `order_build.py` 뒤 그림이 다 사라졌다 | order.json 을 새로 쓰면 img 칸이 날아간다 | 반드시 뒤에 `img_link.py` |
