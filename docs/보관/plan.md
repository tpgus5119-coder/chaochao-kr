# 베트남어 스터디 앱 — 기획서 v1 (2026-08-20)

## 0. 한 줄 정의
> **동기 몇 명이 매일 15분씩, 같은 단어 10개와 문형 틀 2개를 배우고
> 그걸로 서로 대화하게 만드는 웹페이지.**

## 1. 확정된 전제 (사용자 결정)
| 항목 | 결정 |
|---|---|
| 목적 | **업무 — 생산·제조 현장 중심** (+ 일상 표현 보조). 업종 미정 → **업종 무관 공통 어휘**로 간다 |
| 발음 기준 | **v1은 북부(하노이) 단독** — 남부는 v2 (무료 TTS에 남부 화자가 없음) |
| 진도 | **신규는 전원 공통 / 복습은 개인 자율** |
| 하루 분량 | 단어 10개 + 문형 틀 2개 |
| 결과물 | 앱 아닌 **웹** (폰·PC 공용) |
| 범위 | **완성도 높은 앱 아님. 간단·심플 기능만** |

## 2. 조사에서 나온 설계 근거 (요약)
자세한 근거는 `research-textbooks.md`.

1. 국내 초급 교재 5종 + 국가 표준 교재의 **목차 순서가 사실상 동일** → 그대로 뼈대로 쓴다.
2. **모든 교재·기관이 1과(또는 Day 0)를 문자·성조에 통째로 쓴다** → Day 0 필수.
3. 국내 1위 교재(GO! 독학)가 **북부 본문 + 남부 발음 별도 제공** → 우리 결정과 일치.
4. 초중급 회화를 233패턴이 커버 → **A1은 틀 40~60개면 충분**. 틀 1개당 예문 5개가 시장 밀도.
5. **생산·제조 현장 초급 교재는 시장에 없다** → 여기가 우리 자리.
6. 현지 최대 기관 USSH 기준 **A1 = 80시간**. 하루 15분×주5일이면 A1까지 약 15개월.
   → 앱은 어휘·발음·복습 담당, 나머지는 대화 미션이 벌충.

## 3. v1 기능 — 딱 5개만 만든다

### ① 오늘의 카드
- 단어 10개 + 문형 틀 2개
- 카드 앞면: **베트남어 철자(성조 부호 포함)** + 🔊 버튼
- 카드 뒷면: 한국어 뜻 + 한자어 힌트(있을 때만)
- **한글 독음은 기본 숨김**, 탭하면 열림. 14일 뒤 자동으로 안 나옴

### ② 소리
- 단어·예문마다 MP3. **남/여 목소리 토글** 1개 (북부 표준)
- 미리 만들어 둔 정적 파일. 재생만 함. 녹음·채점 없음

### ③ 복습 퀴즈
- 문제 유형 2개뿐: **듣고 고르기**(4지선다), **뜻 고르기**(4지선다)
- 간격은 단순 4단계: 맞추면 `1일 → 3일 → 7일 → 14일`, 틀리면 1일로 복귀
- 복습은 개인 자율 (기기에만 저장)

### ④ 오늘의 대화 미션
- 카드 1장. 앱은 **보여주기만** 한다 (채팅 기능 없음 — 대화는 단톡방에서)
- 형식: 역할 A/B + 써야 할 틀 + **정보차 과제**(상대만 아는 정보를 알아내기)

### ⑤ 진도 표시
- `Day 7 / 완료 ✔` 수준. 스트릭·랭킹·알림 전부 없음

### v1에서 안 만드는 것 (명시적으로 뺀다)
로그인·서버·계정 / 녹음·발음 자동채점 / 채팅 / 알림·푸시 / 스트릭·랭킹 /
문법 설명 페이지 / 쓰기 연습 / 진도 동기화

## 4. 만드는 방법 (기술)

```
베트남어-어플/
├─ index.html          ← 화면 전부 (한 파일)
├─ app.js              ← 로직 (카드/퀴즈/간격)
├─ style.css
├─ data/
│   └─ days.json       ← 커리큘럼 전체 (단어·틀·미션)
└─ audio/
    ├─ n/  (북부)
    └─ s/  (남부)
```
- **서버 없음.** 진도는 브라우저 `localStorage`에 저장
- 배포: GitHub Pages (무료, 링크만 공유하면 폰에서 바로 열림)
- 홈 화면에 추가하면 앱처럼 보임 (PWA는 v2에서)

### 데이터 형식 (days.json)
```json
{
  "day": 1,
  "theme": "인사",
  "words": [
    { "vi": "chào", "ko": "안녕", "kr_read": "짜오", "tone": "평성", "hanja": null,
      "audio": "d01_01" }
  ],
  "frames": [
    { "vi": "Chào {A}!", "ko": "{A} 안녕하세요!", "examples": ["Chào anh!", "Chào chị!"] }
  ],
  "mission": {
    "goal": "서로의 호칭을 정하라",
    "a": "당신은 27살입니다", "b": "당신은 31살입니다"
  }
}
```
JSON만 채우면 앱이 굴러간다. **코드는 한 번 만들고, 이후엔 데이터만 늘린다.**

## 5. 커리큘럼 (v1 = 4주치만 만든다)

| 구간 | 내용 | 단어 | 비고 |
|---|---|---|---|
| **Day 0** | 문자 · 성조 6개 · 발음 | — | 신규 단어 없음. 듣고 구분만 |
| Day 1~5 | 인사 / 호칭 / 이름 / 소개 | 50 | 호칭은 한국어와 같은 구조 → 유리 |
| Day 6~10 | 숫자 / 수량 / 시간 / 요일 | 50 | 현장 수량 표현의 기초 |
| Day 11~15 | **작업 지시 / 수량·불량** | 50 | 우리 고유 구간 |
| Day 16~20 | **안전 / 교대 / 설비·공구** | 50 | 우리 고유 구간 |

- 주 5일 신규 + 주 2일 복습 전용 → **4주 = 200단어 + 40틀**
- Day 11부터는 **새 문법을 얹지 않는다.** Day 1~10의 틀에 현장 어휘만 갈아끼운다
- 현장 어휘 선정은 KOSHA 한베 용어사전을 **참고만** 하고 직접 작성 (라이선스 §A-4)

## 7. 잘 되고 있는지 재는 법 (간단히)
- 주 1회: **7일 이상 지난 단어**로 20문항 (오늘 배운 걸 오늘 재면 아무 의미 없음)
- 목표선: 20문항 중 **14개 이상**이면 분량 유지, 10개 미만이면 하루 7개로 줄임

## 8. 음성 조달 — 확정: edge-tts (2026-08-20 실측)

`pip install edge-tts`. **무료 · 계정 없음 · 카드 등록 없음 · API 키 없음.**
Microsoft Edge의 읽어주기 엔진을 호출한다. 실제로 뽑아서 확인 완료.

| 화자 | 성별 | 지역 |
|---|---|---|
| `vi-VN-HoaiMyNeural` | 여 | 북부(하노이) 표준 |
| `vi-VN-NamMinhNeural` | 남 | 북부(하노이) 표준 |

- 출력: MP3 48kbps / 24kHz / 모노. 단어 ≈10KB, 문장 ≈35KB
- 예상 총량: 단어 200×2 ≈ 4MB + 예문 400×2 ≈ 28MB = **약 32MB**
- 성조 학습용은 `--rate=-20%` 로 느리게 한 벌 더 뽑는다

**한계(기록)**: vi-VN 화자 2종이 모두 북부다. **남부 음성은 이 방법으로 얻을 수 없다.**
→ v1은 북부 단독. 남부는 v2에서 원어민 녹음 또는 유료 TTS로 보충.

검토했던 대안:
- Google Cloud TTS — 무료한도 월 400만자(Standard/WaveNet)·100만자(Neural2). 필요량 4만자라 **요금은 0원이지만 카드 등록 필요**. 보류.
- Piper (`vi_VN-25hours_single-low`) — 완전 오프라인·오픈소스지만 품질 low 등급. 보류.

# v2 변경 (2026-08-20) — 완전 초보 기준

사용자 확인: **동기들이 베트남어를 전혀 모른다.** 이에 따라 두 가지를 바꿨다.

## 1. 준비 구간 1일 → 3일
v1의 Day 0은 성조만 다뤘다. 아무것도 모르는 사람에게는 알파벳부터 필요하다.

| | 내용 |
|---|---|
| 준비 1 | 글자와 모음 12개 (ă â ê ô ơ ư, 그리고 đ) |
| 준비 2 | 성조 6개 |
| 준비 3 | 헷갈리는 자음 12개 (특히 **d는 ㄷ이 아니다**) |

근거는 `research-textbooks.md` §A-1 — 국가 표준 교재도, 현지 대학도, 시판 교재도
예외 없이 1과 전체를 문자·발음에 쓴다.

## 2. 하루 2문장 → **4문장 (일상 2 + 현장 2)** — 사용자 지시
v1은 '문형 틀 2개 + 예문 5개' 구조였다. v2는 **문장 4개**로 바꾸되,
틀의 이점(갈아끼우기)은 문장마다 **변형 2개**를 붙여 유지했다.

문장 하나의 구성:
- 베트남어 + 한국어 + 🔊(보통/느림)
- **단어별 풀이(gloss)** ← 신규. 초보에게 통문장은 뜻 없는 소리 덩어리다
- 한글 발음 (숨김, 14일 뒤 소멸)
- 갈아끼운 변형 2개

결과: 문장 80개 + 변형 160개 = **화면에 나오는 문장 240개**.

## 3. 어휘 순서 재배치
'Tôi không hiểu(못 알아들었어요)'를 **Day 20 → Day 4로 앞당겼다.**
아무것도 모르는 사람이 20일을 기다려야 할 문장이 아니다.
막혔을 때 한국어로 도망가지 않게 해주는 안전장치라, 첫 주에 있어야 한다.

## 4. 검증 자동화
`tools/assemble.py` 가 두 가지를 막는다.
- 단어 중복
- **아직 안 배운 낱말이 문장에 섞이는 것** (누적 어휘 대조, 엄격)

초기 검사에서 8건이 걸렸고 전부 수정했다. 현재 위반 0건.
검증기 자체에도 구멍이 있었다 — 문장 첫 글자가 대문자라 무조건 건너뛰고 있어서
문두의 미학습 단어를 놓쳤다(`Đợi`). 고유명사 화이트리스트 방식으로 바꿔 막았다.

## 5. 커리큘럼 원본은 코드다
`data/days.json`은 이제 **생성물**이다. 직접 고치지 않는다.
원본은 `tools/build_days.py` / `build_p2.py` / `build_p3.py`.
