# 세 모델 견주기 — 짜오짜오 운영에 무엇이 필요한가

대표님 물음 (2026-09-01): Qwen3.5 9B · Qwen3-VL 8B · Gemma 3 12B 를 앱 운영 일 전체로 비교.

## 먼저 — 재 본 것과 못 재 본 것을 갈라 적는다
- **재 봄**: Qwen3.5 9B. 이 맥에서 오늘 직접 돌렸다
- **못 재 봄**: Qwen3-VL 8B · Gemma 3 12B. 받은 적이 없다.
  아래 값은 **크기와 알려진 성질로 미룬 짐작**이다. 받아서 재기 전엔 확정이 아니다

## 이 기계의 한계 (오늘 실측)
M4 Pro · 24GB. 10.4GB 모델은 잘 돈다(낱말 100개 117초).
**16GB 모델은 간단한 요청에 300초를 넘겨 실패**했다 — 메모리가 아니라 대역폭이 못 버틴다.
따라서 쓸 수 있는 한계는 **10~12GB**다.

| | Qwen3.5 9B | Qwen3-VL 8B | Gemma 3 12B |
|---|---|---|---|
| 크기(대략) | 10.4GB **실측** | 7~9GB | 9~12GB |
| 이 맥에서 | **잘 돎(실측)** | 잘 돌 것 | 한계선 |
| 글 읽고 쓰기 | ○ | ○ | ○ |
| **그림 보기** | **✗** | **○** | **○** |
| **소리 듣기** | ✗ | ✗ | ✗ |
| 깊은 생각(단계 밟기) | ○ | ○ | 약함 |
| 한국어 | 쓸 만함 **실측** | 비슷할 것 | 좋은 편 |
| 베트남어 | 약함 **실측** | 약할 것 | 약할 것 |
| 긴 글 담기 | 16K로 씀 | 비슷 | 더 김 |

**셋 다 귀는 없다.** 소리를 듣고 판정하는 일은 어떤 모델도 못 한다 — 파형을 재야 한다.

## 결론

**하나만 고른다면 Qwen3-VL 8B.**
지금 9B 가 하는 글 일을 거의 그대로 하면서 **그림까지 본다.** 크기도 작아 더 빠를 수 있다.

**Gemma 3 12B** 는 한국어가 조금 나을 수 있으나 **한계선 크기**라 그림 굽는 것과 부딪히고,
깊은 생각이 약하다. 이 일에는 이득이 크지 않다.

**Qwen3.5 9B 를 지울 이유는 없다.** 글 일은 이미 재 봤고 잘 돈다.
디스크가 넉넉하면 둘을 두고 **일에 따라 갈아 끼우는 것**이 낫다 (tools/ai.py 가 이미 그렇게 한다).

**가장 큰 깨달음**: 스물다섯 가지 일 가운데 **열넷이 기계 몫**이다.
모델을 고르는 것보다 **셀 수 있는 일을 세는 것**이 더 많이 아낀다.
