### 4-3. 설정 — 공식 문서로 검증한 값 (2026-08-31 재확인)

`tools/gen_word_img.py` 안에 박혀 있고, 앱 화면에서 무엇을 만지든 **스크립트가 보내는 값이 이긴다.**

| 항목 | 값 | 근거 |
|---|---|---|
| 모델 | **FLUX.1 [schnell]** (q8p) | **Apache 2.0 → 상업 이용 자유.** dev 판은 비상업이라 쓰면 안 된다 |
| steps | **8** | BFL 공식 기본값은 4, Draw Things 공식 위키는 schnell 을 "4-8". 실측에서 8이 사람 몸·소품이 뚜렷하게 나아 8로 올렸다(22초→35초) |
| cfg(Text Guidance) | **1 = 끔** | BFL 공식: 가이던스는 flux-dev 전용. schnell 은 `guidance_embed=False` |
| shift | **1 = 끔** | BFL 공식 코드가 schnell 에서만 시프트를 끈다: `shift=(name != "flux-schnell")`. 위키의 "Shift 2.8-4" 는 dev 용이다 |
| 샘플러 | **Euler A Trailing** | Draw Things 가 Trailing 계열을 권한다. 실측 39.7초(DPM++2M Karras 는 68.7초) |
| 크기 | **512×512 → 384 로 줄여 저장** | 1024 로도 구워 비교했더니 **512 가 낫다**. 1024 는 같은 스텝을 4배 넓은 화면에 나눠 쓰느라 그림이 밋밋해진다(침대·배 그림에서 소품이 사라졌다) |

**부정 프롬프트(negative prompt)는 아예 안 먹는다.** schnell 은 CFG 를 안 쓰기 때문이다.
앱 설정에 "text, watermark…" 가 적혀 있어도 무효다. 그리고 프롬프트 안에 "no text" 를 쓰면
확산 모델이 그것을 긍정으로 읽어 **오히려 글자를 불러온다**(전에 '손 감춰라'가 손을 불렀다).

### 4-4. 남은 장수 세기

```bash
cd "/Users/leesehyeon/베트남어-어플" && python3 -c "
import json,pathlib,re,hashlib,unicodedata as U
R=pathlib.Path('.')
pr=json.loads((R/'data/_imgprompts.json').read_text(encoding='utf-8'))
o=json.loads((R/'data/order.json').read_text(encoding='utf-8'))
def walk(v):
    for t in (v.get('tracks') or [v]):
        for c in t['chapters']:
            for l in c['lessons']: yield from l['words']
need=set()
for v in o['vols']:
    for w in walk(v):
        if w.get('img'): continue
        k=re.sub(r'\s+',' ',U.normalize('NFC',w['ko']).split('/')[0].split('(')[0]).strip()
        if k in pr: need.add(k)
miss=[k for k in need if not (R/'img'/('w-'+hashlib.sha1(U.normalize('NFC',k).encode()).hexdigest()[:10]+'.webp')).exists()]
print('아직 안 구운 낱말', len(miss))"
```

### 4-5. 파일 이름 규칙

| 이름꼴 | 무엇 | 씨앗 |
|---|---|---|
| `w-<해시10>.webp` | 지금 과정 낱말 그림 | **한국어 뜻**의 sha1 앞 10자. 베트남어가 아니다 — 뜻이 같으면 두 낱말이 한 그림을 나눠 쓴다 |
| `d<강번호>-<슬러그>.webp` | 옛 days.json 강별 그림 | 베트남어를 ASCII 로 눕힌 것 |
| `x-<슬러그>.webp` | 여러 강이 나눠 쓰는 그림 | 같은 슬러그 |
| `cvv-`/`cvk-`/`cvn-<n>.webp` | 챕터 표지 | `gen_covers.py` 가 글자는 PIL 로 직접 찍는다(확산 모델은 한글을 깬다) |

씨앗이 파일 이름 해시라서 **다시 돌려도 같은 그림이 나온다.** 이미 있는 파일은 건너뛴다.

## 7. 데이터 지도

### order.json 이 본체다 (days.json 이 아니다)

```
data/order.json (1.6MB) — 일곱 권 과정 본체
├ vols[0..3]  일상 (교재 2~5권) → chapters → lessons → words(한 강 15낱말)
├ vols[4]     직무 (6권) → tracks(갈래 16) → chapters → lessons → words
└ gramwords   문법 용어 22개
```
- **권에 이름이 없다.** 번호는 app.js 가 붙인다(vols[0]이 화면의 '2권').
- 1권(문법)은 `data/grammar.json`, 7권(바로알기)은 `data/know.json` 에 따로 있다.
- `data/days.json` 은 **옛 108일 자료**(낱말 1,080). 준비 과정·성조 훈련·대화문·미션은 여기에만 있다.

### 낱말 한 장의 칸

```json
{"vi":"một trăm","ko":"백","kr":"못 짬","krs":"목 짬",
 "gi":"17181920","sr":1,"core":4,
 "ex":{"vi":"…","ko":"…","kr":"…","krs":"…"},
 "img":"d102-tram.webp"}
```

| 칸 | 뜻 |
|---|---|
| `vi` `ko` | 베트남어 · 한국어 뜻 (모든 낱말에 있다) |
| `kr` `krs` | **북부** · **남부** 한글 발음. 손으로 적는 게 아니라 `tools/vi_kr.py` 가 만든다 |
| `ex` | 예문. **예문이 없으면 order_build 가 그 낱말을 버린다** |
| `sr` `gi` `core` | 선배 시험에 나온 낱말(별표) · 기수 번호 · 겹친 기수 수 |
| `img` | 그림 파일 이름 |
| `hanja` | 베트남어 낱말의 한월 어원 한자 (thứ hai = 次二) |
| `alt` | 같은 뜻으로 한 카드에 함께 실린 짝 |
| `south` | 남부에서 아예 다른 말을 쓸 때 |

### 무엇이 자동 생성인가

**`data/` 안의 .json 은 전부 자동 생성이다.** 90개를 대조했고 예외는 하나뿐:
- **`data/_patch_days.json`** — 손으로 고쳐도 되는 유일한 자료. `apply_patches.py` 가 빌드 끝에 다시 얹는다.

이름이 `_` 로 시작하면 도구끼리 주고받는 중간 재료, `_` 없으면 앱이 읽는 완성물이다.

| 파일 | 만드는 도구 |
|---|---|
| `order.json` | `order_build.py` → `img_link.py`(img 칸) |
| `days.json` | `build_all.sh` 전체 |
| `audio_index.json` | `gen_audio.py`, `gen_ko_audio.py` |
| `_imgprompts.json` | `img_prompt_gen.py` |
| `index.html`·`sw.js` 의 판번호 | `stamp.py` |

### 남은 일

1. **원어민 음성 검수** — 소리는 4개 목소리 전부 빠짐 0 이 되었지만, 기계로는
   '깨졌는지·성조 방향이 맞는지'까지만 안다. **자연스러운지는 사람이 들어야 한다.**
2. **그림 내용 검수 반영** — `img_audit.py` 결과가 `data/_imgok.json` 에 쌓인다.
   **판정만 하고 지우지는 않는다**(적용 도구가 없다). 추상어 그림을 뗄지는 사람이 정한다.
3. **`club_worker.js` 배포 확인** — 커밋(e50d92ca8)은 됐지만 **깃허브에 push 도 안 됐고**,
   Cloudflare 대시보드에 올라갔는지도 확인 안 됨. 실제로 계정 탈퇴를 한 번 해 봐야 안다.
4. **원어민 음성 검수** — 기계로는 "깨졌는지"만 안다. "자연스러운지"는 사람이 들어야 한다.
5. **낱말 흠 손질** — 뜻에 영어 9개, f·j·w·z 4개, 너무 긴 뜻 1개.
6. **기사 로봇 점검** — 자료의 최신 기사가 08-28 이다(오늘 08-31). 로봇은 08-29 에도 돌았는데
   새 날짜가 안 늘었다. `.github/workflows/news.yml` 실행 기록을 깃허브에서 봐야 한다.
7. **고유명사 대문자 3개** — `giáng sinh → Giáng Sinh` · `bệnh viện đông y → Bệnh viện Đông y`
   · `viễn đông → Viễn Đông`. **고치면 소리 파일 이름(해시)이 바뀌어 그 셋의 mp3 를 다시 구워야 한다.**
   남부 TTS 가 지금 안 도니(viphoneme 없음) 그것부터 고치고 함께 처리하라.
8. **선배 자료(senior_pool)의 철자 131개** — 앱에는 안 나오지만 별표(sr) 판정의 근거다.
