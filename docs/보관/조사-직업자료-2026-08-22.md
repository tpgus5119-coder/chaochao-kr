# 직업 목적 베트남어 자료 전 세계 조사 (2026-08-22)

5방향 병렬 조사: 한국어권 / EPS-TOPIK 역방향 / 영어·중국어권 / 베트남 현지 / 학술(LSP).

## 결론 한 줄
"한국인 왕초보가 베트남 **공장 취업**을 목표로 문자·성조부터 라인 현장 회화까지"를 다루는
자료는 **전 세계 어느 언어로도 출판된 것이 없다.** 가장 가까운 원형은 대만 교재와
한국의 역방향 국가 교재(EPS-TOPIK)이며, 우리 앱은 이 공백을 채우는 첫 시도가 맞다.

### 2. EPS-TOPIK 한국어 표준교재 2권 (한국산업인력공단, 무료 PDF) — 뒤집으면 우리 것
베트남 노동자에게 '한국 공장 한국어'를 가르치는 국가 표준. 30과 목차 확보:
- [직장 문화 31~34] 복장·근무 태도 / 회사 시설 / 동료 관계 / 성희롱 예방
- [직무 35~52] 작업장 관리 / 출하 / 기계가공·조립 / 금속 / 플라스틱 성형 / **섬유 제조** / … 공정별 18과
- [안전 53~56] 안전표지 / 수칙 / 보호구 / 산업재해·응급처치
- [법·제도 57~60] 고용허가제 / 근로계준법(계약서·급여명세) / 출입국 / 보험
대화 공식: **(신입이 문제 호소) → (선임이 도구+방법 지시) → (안전 당부)** 3박자.
과당 어휘 2묶음 + 치환 드릴. https://eps.hrdkorea.or.kr/epstopik/book/std/standardBookList.do

## 학술 근거 (커리큘럼 순서·구성의 논거)
- **Long 2005 (요구 분석)**: 어휘 빈도순이 아니라 **현장 과업의 빈도×중요도** 순으로 배열하라.
- **Jasso-Aguilar 1999**: 회사가 추측한 목록 ≠ 현장 실제 언어. **경험자(선배) 검증 필수** — 삼각검증.
- **Nation 2001/2013**: 고빈도 일반어 핵 + **분야 전문어로 직행**(중간 교양층 생략) — 우리 이중 트랙과 일치.
- **Chung & Nation 2003**: 전문 담화의 20~30%가 전문어 — 전문어를 뒤로 미루면 현장 이해 불성립.
- **van Zeeland & Schmitt 2013**: 듣기는 95% 커버리지(2~3천 단어족)면 기능 — 읽기보다 문턱 낮음.
- **CEFR/ALTE A1 원문**: 직장 A1 = 정형 요청("X 20개 주세요")·짧은 전달("금요일 10시")·숫자/수량/시간까지.
  **안전 표지 이해는 A2 배정**(그림과 함께 가르치라) — 레벨 로드맵 근거.
- **직무통합형 > 일반어학** (Friedenberg 외 2003, Duff 외 2000, MPI/CAL 평가).
- **언어훈련→고용·소득 인과** (프랑스 Lochmann 2019: 참여율 +15~27%p / 핀란드 / 덴마크 NBER w26834).
