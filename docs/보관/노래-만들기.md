# 노래 만들기 (수노용)

## 왜 노래인가 — 그리고 무엇을 노래로 만들어야 하는가

Ludke, Ferreira & Overy(2013)가 성인 60명에게 헝가리어(전혀 모르는 언어)를 15분 가르쳤다.
세 조건 — ① 말하기 ② **리듬 있게** 말하기 ③ **노래**.

노래 조건이 유의하게 우수했다(p<.05). 특히 **구절을 그대로 말해내는 과제**에서.
나이·성별·기분·작업기억·음악 훈련으로 설명되지 않았다.

**중요한 건 ②다. 리듬만 넣은 조건은 노래만큼 좋지 않았다.**
→ 박자가 아니라 **멜로디**가 일한다. 랩이나 챈트로는 이 효과가 안 나온다.

그리고 대상이 **구절 단위**였다. 단어를 하나씩 노래로 외우는 것에 대한 근거가 아니다.
→ **우리가 노래로 만들 것은 "그날의 대화 2문장"이다. 단어 목록이 아니다.**

## 수노 설정 (권장)

| 항목 | 값 | 이유 |
|---|---|---|
| 길이 | **30~60초** | 대화 2문장이면 충분하다. 길면 안 듣는다 |
| 빠르기 | **70~90 BPM (느리게)** | 성조가 뭉개지면 다른 단어가 된다 |
| 스타일 | `simple acoustic, clear vocals, childrens song, slow` | 반주가 크면 성조가 묻힌다 |
| 목소리 | 남녀 한 명씩 (A/B 역할) | 대화니까 |
| 반복 | 같은 두 줄을 **3~4번** 반복 | 15분 실험에서도 효과가 났다. 반복이 핵심 |

**꼭 넣을 것**: 프롬프트에 `Vietnamese language` 를 명시.
**피할 것**: 빠른 템포, 드럼 강한 편곡, 화음 겹치기 — 전부 성조를 가린다.

## 파일 넣는 법

만든 mp3를 이 이름으로 저장해서 `audio/song/` 에 넣는다.

```
audio/song/day01.mp3   ← Day 1
audio/song/day02.mp3   ← Day 2
...
audio/song/day20.mp3
```

파일을 넣으면 그 Day의 대화 카드에 **🎵 오늘의 노래** 버튼이 저절로 생긴다.
없는 날은 버튼이 안 뜬다. 몇 개만 만들어도 된다.

넣은 뒤 배포:
```
python3 tools/stamp.py && git add -A && git commit -m "노래 추가" && git push
```

## 우선순위

전부 만들 필요 없다. **Day 1·5·8·10** 부터 만드는 걸 권한다.
- Day 1 인사 — 가장 많이 쓴다
- Day 5 안부 — `có ... không?` 틀이 앞으로 계속 나온다
- Day 8 못 알아들었을 때 — 막혔을 때 반사적으로 나와야 하는 문장
- Day 10 작별 — 1주차 마무리

## 만든 뒤 확인할 것

노래를 들으며 **성조가 살아 있는지** 확인하라. 멜로디가 성조를 덮어버리면 소용없다.
- `à`(내려감)를 올려서 부르지 않는지
- `ả`(내렸다 올림)와 `ã`(끊었다 올림)가 구별되는지

애매하면 그 곡은 버리고 더 느리게 다시 뽑는 게 낫다.
잘못된 성조를 멜로디로 외우면 고치기가 훨씬 어렵다.
