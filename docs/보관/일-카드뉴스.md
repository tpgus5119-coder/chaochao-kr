## 4. 도구가 하는 일 (고칠 일이 생기면 여기를 본다)

| 도구 | 하는 일 | 자주 고치는 자리 |
|---|---|---|
| `tools/news_sum5.py` | 기사 본문 → **여섯 줄 풀이** (AI) | `ASK` 상수 = 말투·길이 규칙 |
| `tools/card_news.py` | 카드 두 장 그리기 | `W, H`(크기) · `LS_*`/`LH_*`(자간·행간) · `SCENES`(배경 장면) |
| `tools/card_export.py` | 바탕화면 날짜 폴더 + `기사링크.txt` | 쪽지 문구 |
| `tools/card_ppt.py` | 고칠 수 있는 파워포인트 | 글상자 자리·크기 |
| `tools/img_watch.py` | 위 넷을 매시간 묶어 돌린다 | `make_cards()` |

### 말투 규칙 (대표님 확정, 2026-08-31)

`news_sum5.py` 의 `ASK` 에 적혀 있다. **바꾸려면 여기만 고친다.**
- 존댓말이되 **`~요`** 로 끝낸다. `~습니다`·`~한다` 금지
- 신문 문장을 베끼지 말고 **옆에서 설명해 주듯** 푼다
- 여섯 줄, 한 줄 **28자 안팎** (길면 카드에서 두 줄로 접혀 답답해진다)
- 마지막 줄은 **우리에게 무슨 뜻인지**

### 카드 만드는 규칙 (`card_news.py`)

- 정사각형 1080×1080
- **글자는 확산 모델로 그리지 않는다.** 배경만 AI 가 굽고 글자는 파이썬(PIL)이 찍는다
  (확산 모델은 한글을 깬다)
- 그림 위에 **카드 전체를 덮는 밝은 막**을 씌운다 → 글이 어디에 놓여도 읽힌다
- 자리에 맞춰 **글꼴을 키운다**. 줄 간격만 벌리면 허전해진다
- `wrap_balanced()` 가 외톨이 줄을 없앤다(마지막 줄에 마침표 하나만 떨어지던 것)
- 배경 장면은 갈래마다 여럿 두고 **기사 제목에서 씨앗을 뽑는다**
  — 안 그러면 같은 갈래 기사 둘이 똑같은 그림을 쓴다(실제로 그랬다)

## 5. AI 를 로컬 모델(Qwen 등)로 바꾸려면

지금 `news_sum5.py` 는 중계 워커(`https://viet-ai.chaochao-app.workers.dev`)를 부른다.
열쇠는 스크립트가 아니라 **워커 금고**에 있다. 로컬 모델로 바꾸려면 네 줄을 고친다:

| 자리 | 지금 | 바꿀 것 |
|---|---|---|
| `URL` | 워커 주소 | `http://localhost:1234/v1/chat/completions` |
| 본문 | `{"contents":[{"parts":[{"text": ...}]}]}` | `{"model": "...", "messages":[{"role":"user","content": ...}]}` |
| `Origin` 헤더 | 있음 | 지운다 |
| 답 읽기 | `j["candidates"][0]["content"]["parts"][0]["text"]` | `j["choices"][0]["message"]["content"]` |

**로컬 모델을 쓸 때 꼭 해야 하는 두 가지**
1. 생각을 `<think>…</think>` 로 먼저 뱉는 모델이 많다 → 이미 `re.sub(r"(?s)<think>.*?</think>", "", t)` 를 넣어 뒀다
2. 문맥이 좁으면 기사 본문을 줄인다 → `body[:3500]` 을 `[:1500]` 쯤으로

**주의**: 요약 품질이 카드의 전부다. 로컬 모델로 바꿨으면 **반드시 카드를 눈으로 보고**
말투(`~요`)와 길이(28자)가 지켜졌는지 확인하라.
