## 4. 5종 교차 목차 분석 — 초급 교재는 순서가 거의 동일하다

`가장 쉬운 독학`, `GO! 독학`, `VSL 1`, `하이`, `열공`의 목차를 겹쳐보면:

```
[0단계] 문자 · 발음 · 성조          ← 전 교재가 별도 파트로 분리, 분량 10~15%
[1단계] 인사 → 이름/소개 → 국적 → 직업/사는곳 → 가족
[2단계] 숫자 → 시간/요일 → 날짜 → 날씨
[3단계] 가격/쇼핑 → 식당/주문 → 교통/길찾기
[4단계] 전화 → 병원/몸 → 경험(과거) → 비교급
```
이 골격은 CEFR A1 표준 주제군과 사실상 동일하고, 베트남 정부 공식
**외국인용 베트남어 능력 6단계 기준(교육훈련부 고시 17/2015/TT-BGDĐT, CEFR 대응)** 의
Bậc 1(=A1)에 대응한다.

> 시사점 C: **이 골격은 검증된 것이므로 그대로 뼈대로 쓴다.** 창의성을 발휘할 자리가 아니다.

## 5. 시장의 빈 구멍 — 여기가 우리 앱의 존재 이유

조사한 국내 시판 교재 중 **생산·제조 현장을 다루는 초급 교재는 없다.**
비즈니스 교재는 있으나 무역·사무 중심이고, 공장 라인·품질·안전 어휘는 비어 있다.

그 구멍을 메우는 **공공 자료**를 확인했다:

| 자료 | 발행 | 형식 | 이용조건 |
|---|---|---|---|
| **산업안전보건 한베 용어사전** | 한국산업안전보건공단(KOSHA) | PDF 162p, 가나다순 + 색인 | 공공저작물 **제4유형** |
| 외국인근로자 안전보건수칙 10계명 포스터 (베트남어) | KOSHA | 포스터/음원 | 공공누리 |
| 외국인근로자 안전매뉴얼 (베트남어 포함) | 서울시 | PDF | 공공누리 |
| 다국어 안전표지 자료 (11개국) | 중소기업중앙회 | 이미지 | 공공누리 |
| 베트남어 A1 교재 1~6과 + MP3 | 단국대 특수외국어사업단 | PDF+MP3 무료 | 확인 필요 |

> **경고 (라이선스)**: KOSHA 용어사전은 공공저작물 **제4유형 = 출처표시 + 상업적이용금지 + 변경금지**.
> 즉 **파일을 그대로 재배포하거나 가공해 앱에 싣는 것은 불가**하다.
> 허용되는 사용은 "**어떤 어휘를 가르칠지 정하는 참고 자료**"까지다.
> 단어 목록·예문·음성은 우리가 새로 작성해야 한다. 이 선을 넘지 않는다.

## 7. 패턴(문형 틀) 설계 참고 — 베트남어 회화 핵심패턴 233

- 초중급 회화를 **233개 패턴**으로 커버. 패턴 1개당 **핵심 문장 5개 → 실제 대화** 2단계 구성.
- MP3를 3종으로 분리 제공: ① 베트남어만 ② 통역(한→베) ③ 미니북용.

> 시사점 D: **패턴 1개 : 예문 5개** 비율이 시장 검증된 밀도다.
> 233개가 초중급 전체이므로, **A1 범위는 40~60개 틀이면 충분**하다는 역산이 나온다.
> 시사점 E: **음성을 "베트남어만/통역본"으로 나눠 제공**하는 건 표준 관행이다. 우리도 나눈다.

## 8. 한글 독음 표기에 대한 시장 실태

`GO! 독학`을 포함한 국내 첫걸음 교재 대부분이 **한글 독음을 제공**한다.
즉 "한글 독음을 넣는다" 자체는 시장 표준이며, 동기들이 이걸 원하는 것도 자연스럽다.

다만 어느 교재도 한글 독음으로 **성조를 표현하지 못한다**(`ma/mà/má/mả/mã/mạ` → 전부 "마").
그래서 상위 교재들은 예외 없이 **발음 트레이닝을 별도 영상/음원으로 분리**해 보완한다(§3).

> 결론: 한글 독음은 **넣되**, ① 기본 숨김·탭하여 열람 ② 성조 부호 병기 ③ 2주 후 자동 소멸.
> 그리고 발음 훈련은 본문과 분리된 별도 트랙으로 둔다.

## 10. 조사 결론 (설계에 직접 반영할 8가지)

1. **A1 골격은 5종 교재 공통 순서를 그대로 쓴다** (§4). 새로 짜지 않는다.
2. **0주차는 문자·발음·성조 전용**으로 뺀다. 전 교재가 그렇게 한다.
3. **북부 기본 + 남부 음성 병기**는 국내 1위 교재와 같은 전략이다. 확정.
4. **틀(패턴)은 A1 범위 40~60개**면 충분하다 (233개 역산).
5. **틀 1개당 예문 5개** 밀도를 따른다.
6. **음성은 "베트남어만 / 한-베 통역" 2종**으로 나눈다.
7. **생산제조 어휘는 시판 교재에 없다.** KOSHA 용어사전을 *참고만* 해서 직접 만든다(라이선스 §5).
8. 단어 선정은 **vn-freqs 구어 빈도 × 현장 필요도** 두 축으로 교차한다.
