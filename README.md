```

  [ 오늘의 대화 · 이름 묻고 답하기 ]
       ▶ 대화 전체 듣기
 ┌────────────────────────────┐
 │ Ⓐ  🔊 🐢                    │
```

## 실행
```
python3 -m http.server 8899
```
브라우저에서 http://localhost:8899 열기.

> **8899 여야 한다.** Cloudflare 워커(AI·동아리)가 허용하는 개발용 주소가 이것뿐이라,
> 다른 번호로 띄우면 AI·로그인 기능이 403 으로 막힌다.

## 배포
```
python3 tools/stamp.py          # ← 반드시 먼저. 안 하면 옛 화면이 계속 보인다
git add -A && git commit -m "..." && git push
```
`main` 에 push 하면 GitHub Pages 가 1분 안에 반영한다.

> **왜 stamp.py 가 필요한가**: GitHub Pages 는 CSS/JS 에 `max-age=600` 을 붙여

> 주소를 바꿔서 강제로 다시 받게 한다. 내용이 안 바뀌면 해시도 그대로라 헛되이 안 받는다.

## 콘텐츠 늘리기
커리큘럼 원본은 `tools/build_*.py` 다. `data/days.json` 을 직접 고치지 말 것.

```
sh tools/build_all.sh              # 전부 — 차례가 중요하다(아래 참고)
python3 tools/assemble.py          # 검증만 하고 싶을 때
```

`build_all.sh` 가 도는 차례. **이 차례를 지켜야 한다** — 뒤 도구가 앞 도구 결과를
쓰고, 순서를 어기면 조용히 사라지는 것이 생긴다(실제로 8.5강이 통째로 되돌아갔다).

| 차례 | 도구 | 하는 일 |
|---|---|---|
| 1 | `b9.py` 등 `b*.py`·`w*.py` | 커리큘럼 원본 → `data/_b*.json` |
| 2 | `assemble.py --write` | 합치고 검증하고 `days.json` 기록 |
| 3 | `fix10.py` | 한 강 = 낱말 10개로 맞춤 (넘치면 ②강으로 쪼갬) |
| 4 | `img_relink.py` | 이미 구운 그림을 다시 이어 붙임 |
| 5 | `new_dialogs.py` | 쪼개진 강에 대화문 + 강 번호 다시 매김 |
| 6 | `fill_missions.py` | 빈 미션 채움 |
| 7 | `apply_patches.py` | **맨 마지막** — days.json 에만 살아 있던 사용자 지시 수정 되돌림 |
| 8 | `hanja_attach.py` → `gen_covers.py` → `gen_audio.py` → `stamp.py` | 한자·표지·음성·판번호 |

점수와 크레딧 값은 `tools/pricing.py` 가 계산한다 → `docs/scoring-basis.md`.
손으로 고치지 말고 그 파일을 고쳐라.

`assemble.py` 가 막아주는 것: 단어 중복, **아직 안 배운 낱말이 문장에 섞이는 것**.
둘 중 하나라도 걸리면 days.json 을 쓰지 않는다.

`edge-tts` 필요: `pip install edge-tts` (무료·계정 불필요)

### 복습이 어떻게 도는가
```
새 단어 → 1일 → 3일 → 7일 → 14일 → 30일 → 60일
맞히면 다음 칸으로. 틀리면 두 칸 뒤로 (처음으로 되돌리지 않는다)
그리고 틀린 문제는 그 판 안에서 한 번 더 물어본다
```

- **왜 60일까지 가나**: 최적 간격은 "얼마나 오래 기억하고 싶은가"의 비율로 정해진다.
  1주 뒤 목표면 20~40%, 1년 뒤 목표면 5~10%. 반년~1년이 목표라 9~18일에서 시작해 더 늘려야 한다
- **왜 틀려도 처음으로 안 돌리나**: 14일째 잘 알던 단어가 한 번 헛디뎠다고 1일로 떨어지면
  복습 큐가 폭발한다. 두 칸만 내린다
- **3분만 / 전부**: 밀렸을 때 10개만 하고 끊을 수 있다. 짧게 자주가 길게 한 번보다 낫다

### 기록·배지 (2026-08-20 추가)
점수·배지가 **학습**을 만든다는 증거는 약하다. 올리는 건 **참여**다.
그런데 간격 반복은 돌아와야 돌아간다 — 그래서 목표를 **'돌아오는 것'에만** 걸었다.

- **연속 기록(streak)은 안 쓴다.** 하루 끊기면 그만두는 원인이라서.
  대신 **이번 주 5일**, 이틀은 쉬어도 되게 했다
- 숫자 세 개만: 배운 단어 / 끝낸 날 / **소리 낸 횟수**
- 배지 8개는 실제 성취에만 (글자 뗌 · 1주차 · 절반 · 완주 · 100단어 · 성조 8/10 · 50번 소리 · 주 5일)
- **랭킹은 없다.** 서버도 없고, 비교는 늦은 사람을 떨어뜨린다

**일부러 안 넣은 것**
- **"뜻을 먼저 맞혀보세요"** — 외국어 단어에서는 추측이 단서-목표 연결을 **약화**시킨다(핀란드어-폴란드어 실험 4개). 재학습해도 안 뒤집힌다
- **연속 기록(streak)과 랭킹** — streak은 하루 끊기면 이탈로 이어지고, 랭킹은 뒤처진 사람을 떨어뜨린다
- **추상어에 그림** — 중복 정보는 인지부하만 올린다
- **아무 손짓이나** — 뜻과 안 맞는 손짓은 **기억을 떨어뜨린다**. `tools/gestures.py` 에 단어별로 지정했고, 자연스러운 손짓이 없는 36개는 일부러 비워뒀다

## 설계 원칙 (근거는 docs/ 참고)
- **복습이 본체다.** 신규 10개보다 매일 돌아오는 복습 큐가 중요
- **한글 발음은 숨겨둔다.** 탭해야 보이고, 시작 14일 뒤 사라짐 (성조를 담지 못하므로)
- **통문장 앞에 단어별 풀이를 놓는다.** 초보에게 문장은 뜻 없는 소리 덩어리다
- **문장마다 갈아끼운 변형 2개.** 문장 4개 = 실제로는 12개를 본다
- **대화는 정보차 과제로.** "자유롭게 대화해봐"는 초급자끼리 아무것도 못 만든다
